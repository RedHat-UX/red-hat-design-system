## Responsive side navigation

A responsive sidebar navigation using `<rh-drawer>` with
`<rh-navigation-vertical>`. At wide container widths the
drawer is always visible alongside page content. At narrow widths it
switches to an overlay triggered by a menu button.

<rh-cta href="/elements/drawer/demos/#demo-pattern-responsive">View responsive side navigation demo</rh-cta>

## Responsive collapsible side navigation

A collapsible sidebar navigation using `<rh-drawer>` with
`<rh-navigation-vertical>`. At wide container widths the
drawer pushes content aside with a collapse toggle. At narrow widths it
overlaps content instead.

<rh-cta href="/elements/drawer/demos/#demo-pattern-collapsible">View collapsible side navigation demo</rh-cta>
