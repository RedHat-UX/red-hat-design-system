## Progressive enhancement

A scheme dropdown is a native [`<select>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) element. Browsers that support [customizable select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select) show scheme icons and a styled menu which match images of the component on the [Style](/elements/scheme-dropdown/style/) page.

Users of older browsers see a standard select element that lists each scheme label as plain text.
