## Progressive enhancement

A scheme dropdown is a native [`<select>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/select) element. Browsers that support [customizable select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select) show scheme icons and a styled menu, matching the images on the [Style](/elements/scheme-dropdown/style/) page.

Customizable select is not [Baseline](https://developer.mozilla.org/en-US/docs/Glossary/Baseline) because it does not work in some of the most widely used browsers, including Firefox. Browsers without support show a standard select element that lists each scheme label as plain text.
